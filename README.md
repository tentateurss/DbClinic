# DbClinic — Data Base for network Clinic
**Версия:** 1.2
---

## Описание

Система управления сетью клиник. Позволяет управлять клиниками, сотрудниками, пациентами, медицинскими услугами и записями на прием.

---

|       Технология        |    Назначение    |
|:-----------------------:|:----------------:|
|         Java 17         | Язык разработки  |

|     Spring Data JPA     |   Работа с БД    |

## Функциональность

### Административная часть (Admin API)

- Создание, редактирование и удаление клиник
- Управление сотрудниками (врачи, администраторы, медсестры)
- Регистрация и ведение пациентов
- Управление медицинскими услугами
- Полное управление записями на прием
- Изменение статусов записей (подтверждение, отмена, завершение, неявка)

### Публичная часть (Public API)

- Просмотр списка клиник, сотрудников, пациентов, услуг
- Просмотр записей с фильтрацией:
    - По пациенту
    - По врачу
    - По клинике
    - По статусу
    - По диапазону дат
    - Комбинированные фильтры
- Пагинация для всех списков

### Автоматизация

- Автоматическая отметка неявок (CONFIRMED - NO_SHOW) по расписанию
- Валидация переходов статусов (SCHEDULED - CONFIRMED - COMPLETED / CANCELLED)

## Запуск

### Требования

- Java 17
- Maven 3.8+
- Docker и Docker Compose

### Шаги

1. Клонировать репозиторий:
```bash
   git clone https://github.com/username/DbClinic.git
   cd DbClinic
```
2. Сборка проекта:
```bash
   mvn clean package -DskipTests
```   
3. Запустить через Docker Compose:
```bash
   docker-compose up -d --build
```

### Остановка
```bash
  docker-compose down
```  
### Для полной очистки (включая данные БД):
```bash
  docker-compose down -v
```
